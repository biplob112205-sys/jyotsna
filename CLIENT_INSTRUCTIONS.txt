4. HOW TO ADD, EDIT & DELETE REAL CLIENT PROJECTS
================================================================================
Your website currently has 0 demo projects, meaning it is a clean slate ready
for your genuine client work.

A. How to Add a New Project:
----------------------------
1. Open the Admin Panel (`Ctrl + Shift + A` or click `🔒 Studio Vault`).
2. Click on the "Projects" tab.
3. You will see the "Add / Edit Commercial Project" form. Fill in the fields:
   - Project Title : E.g., "Aura Luxe | 4K Brand Film" or "Cyberpunk Theatrical Poster"
   - Category      : Choose from the dropdown:
                     * Poster Design
                     * Banner Design
                     * Social Media Posters
                     * Album Design
                     * Wedding Photo Editing
                     * Ads Poster Design
                     * Cinematic Video Editing
                     * Podcast Editing
                     * Motion Graphics Video
                     * AI Ads Video
                     * AI Documentary Video Editing
                     * Ads Video Editing
   - Category Label: Type the display label (e.g., "Poster Design" or "Cinematic Video")
   - Subtitle      : A short 1-line summary (e.g., "Theatrical print poster with dual-tone grading")
   - Description   : 2-3 sentences explaining your creative process and results.
   - Client Name   : E.g., "Sony Music", "Apex Apparel", or "Confidential Commercial Client"
   - Timeline      : E.g., "48 Hours Turnaround" or "3 Days Delivery"
   - Deliverables  : Comma-separated list (e.g., "4K ProRes 422 Master, 9:16 Viral Reels, Rec.709 LUT")
   - Tools Used    : Comma-separated list (e.g., "Photoshop, Illustrator, DaVinci Resolve")
   - Project Image : 
     * Option 1: Place your image (JPG, PNG, WebP) in the `assets/` folder, then
       type the relative path: `assets/my-project-1.jpg`
     * Option 2: Paste any direct web image link (e.g., from Imgur, Cloudinary,
       AWS S3, or your Google Drive direct link).
4. Click the blue button: "Save Project to Portfolio".
5. Close the Admin modal. Your new project will immediately appear under the
   "Work Showcase" grid and inside the filtered category tabs!

B. How to Edit an Existing Project:
-----------------------------------
1. In the Admin Panel -> "Projects" tab, scroll down to "Existing Projects List".
2. Locate the project you wish to update.
3. Click the blue "Edit" button next to it.
4. The form above will automatically populate with that project's information.
5. Make your edits and click "Save Project to Portfolio".

C. How to Delete a Project:
---------------------------
1. In the Admin Panel -> "Projects" tab, scroll down to "Existing Projects List".
2. Click the red "Delete" button next to the project you wish to remove.
3. Confirm the prompt. The project will be permanently removed from your live site.

8. HOW TO BACKUP & RESTORE YOUR DATA (JSON EXPORT/IMPORT)
================================================================================
All changes you make via the Admin Panel are saved safely in your browser's
persistent LocalStorage. However, if you clear your browser history, change
computers, or want to send your project configuration to someone else, use the
built-in JSON Backup tool!

How to Create a Backup:
-----------------------
1. Open Admin Panel -> Click the "Data Backup & JSON" tab.
2. You will see a text box containing all your projects, brand data, services,
   and settings formatted in clean JSON.
3. Click the button: "📋 Copy CMS JSON to Clipboard".
4. Open a text editor (Notepad, TextEdit, etc.) and paste the text. Save it as
   `my_portfolio_backup.json` on your computer or Google Drive.

How to Restore from a Backup:
-----------------------------
1. Open Admin Panel -> Click the "Data Backup & JSON" tab.
2. Paste your backup JSON text into the text box.
3. Click the button: "📥 Import & Apply JSON".
4. The website will immediately reload with all your projects and settings restored!

                 Dossier, About, Contact, and Admin Modal markup).
- `css/styles.css`: Custom animations, glassmorphism styles, and typography rules.
- `js/app.js`  : Application engine, CMS manager, modal popups, and project rendering.
- `assets/`    : Logo images (`sora-logo-full.jpg`, `sora-logo-circle.png`), icons,
                 and client project image files.

To Hardcode Default Projects Directly:
1. Open `js/app.js` in VS Code or any code editor.
2. Locate `const DEFAULT_CMS_DATA = {` near line 12.
3. Scroll down to `projects: []`.
4. Add your project objects inside the array formatted like this:
   {
     id: "proj-1",
     title: "My Client Project Title",
     category: "poster-design",
     categoryLabel: "Poster Design",
     client: "Brand Name",
     year: "2026",
     timeline: "48 Hours Turnaround",
     deliverables: ["Print Ready CMYK", "Social Formats"],
     tools: ["Photoshop", "Illustrator"],
     image: "assets/my-image.jpg",
     subtitle: "One line summary of the project",
     description: "Full description of the creative direction and deliverables."
   }
5. Save the file.
